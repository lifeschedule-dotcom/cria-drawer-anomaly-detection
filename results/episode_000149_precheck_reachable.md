# CRIA 149 사전 검토 기록

- 경보 시각(초): `[[9.8, 12.633], [23.3, 23.3]]`
- 가정한 접근 조건: 접근 가능으로 가정
- 우선 확인: 접근 경로, 최소 틈새, 개입 작업을 확인하고 접근 제거·분리 대책을 검토한다.
- 실제 위험등급: **판정 보류** — 현장 접근·노출과 감소조치 이행·검증 자료가 제공되지 않았다.

| 확인 항목 | 현장에서 확보할 증빙 | 현장 확인 상태 |
| --- | --- | --- |
| 작업과 배치 | 도면·사진에 그리퍼, 작업물, 위험점, 접근 경로와 최소 틈새를 표시한다. | 미확인 |
| 운전 모드·노출 | 자동 운전, 걸림 해소, 정비에서 누가 얼마나 자주 개입하는지 기록한다. | 미확인 |
| 감소조치 | 적용한 가드·인터록 등과 그 설치 확인 결과를 기록한다. | 미확인 |
| 기능 검증 | 접근 시 정지를 채택했다면 적용 조건에서 정지 시간·거리와 재기동 방지 결과를 첨부한다. | 미확인 |
